# Магазин необычных головоломок и пазлов

## Описание проекта

Полноценный интернет-магазин головоломок и пазлов с каталогом товаров, 
фильтрацией, поиском, корзиной покупок и оформлением заказов.

Лабораторные работы №16, №17, №18, №19 по изучению Django.

## Функционал

### Каталог товаров (№18)
- Просмотр всех товаров
- Фильтрация по категориям и производителям
- Поиск по названию и описанию
- Детальная информация о товаре

### Корзина покупок (№18)
- Добавление товаров в корзину
- Изменение количества товаров
- Удаление товаров из корзины
- Подсчёт общей стоимости 

### Оформление заказа (№19)
- Страница оформления заказа
- Генерация чека в формате Excel
- Отправка чека по электронной почте
- История заказов

### Административная панель
- Управление товарами, категориями, производителями
- Управление заказами и корзинами
- Управление пользователями

## Технологии

- Python 3.x
- Django 6.0+
- SQLite
- Pillow (работа с изображениями)
- openpyxl (генерация Excel файлов)

## Установка и запуск

1. Клонировать репозиторий
2. Создать виртуальное окружение: `python -m venv venv`
3. Активировать: `venv\Scripts\activate`
4. Установить зависимости: `pip install django pillow openpyxl`
5. Применить миграции: `python manage.py migrate`
6. Создать суперпользователя: `python manage.py createsuperuser`
7. Запустить сервер: `python manage.py runserver`

## Структура URL

- `/` - главная страница
- `/catalog/` - каталог товаров
- `/catalog/<id>/` - подробная информация о товаре
- `/cart/` - корзина покупок
- `/cart/add/<id>/` - добавить в корзину
- `/cart/update/<id>/` - обновить количество
- `/cart/remove/<id>/` - удалить из корзины
- `/checkout/` - оформление заказа
- `/about/` - о магазине
- `/author/` - об авторе
- `/admin/` - административная панель
- `/accounts/login/` - вход
- `/accounts/logout/` - выход

## Модели базы данных

- **Category** - категории товаров
- **Manufacturer** - производители
- **Product** - товары (головоломки, пазлы)
- **Cart** - корзины пользователей
- **CartItem** - товары в корзине
- **Order** - заказы *(№19)*
- **OrderItem** - товары в заказах *(№19)*
